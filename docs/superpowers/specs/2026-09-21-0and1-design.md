## 1. Visi

**North star:** membangun (1) **Semesta** — kosmos digital dari bit murni dengan fisika konservatif yang direkayasa agar kompleksitasnya tumbuh terus (open-endedness), dan (2) **Newton** — mesin penemu hukum yang menonton semesta itu dan menemukan hukum generatif/emergennya secara otomatis, diverifikasi eksak terhadap source code semesta — dalam satu loop tertutup.

**Pola jenius yang diikuti:** setiap tokoh yang menginspirasi proyek ini mengambil sesuatu yang abstrak dan memberinya representasi mekanis — Newton (gerak → kalkulus), Shannon (informasi → bit), Gödel (bukti → bilangan), Einstein (ruang-waktu → geometri), Bell (suara → sinyal). Yang masih abstrak hari ini: **open-endedness dan penemuan hukum** — keduanya belum punya "bit"-nya sendiri. 0and1 memberinya: **bit model Newton sebagai satuan open-endedness.**

**Trik epistemik inti:** semesta digital adalah satu-satunya semesta di mana kita memegang source code Tuhan. Hukum yang ditemukan Newton dapat diverifikasi eksak, bukan dinilai anekdotal.

## 5. Substrat (Semesta)

**Kelas:** number-conserving cellular automata (NCCA) k-bit di lattice (dimensi & radius dapat dikonfigurasi), update sinkron dan asinkron, boundary periodik.

**Dasar terverifikasi:** Fredkin–Toffoli conservative logic (komputasi universal kompatibel dengan konservasi; billiard ball model = gate universal dari tumbukan); Margolus BBMCA (reversibel, konservatif, universal; hukum konservasi lokal tidak bergantung pada reversibilitas aturan); flow diagram NCCA mendeskripsikan partikel via barisan kecepatan. → partikel, tumbukan, gate universal **native**, bukan diprogram.

**Peringatan desain (dari scan):** konservasi = **infrastruktur**, bukan open-endedness. Jangan dicampuradukkan.

**Parameter keluarga aturan:** k (bit per sel), radius, mode update, derajat konservasi, knob kekacauan tipe-λ, komponen bergantung-state (Adams 2017: satu-satunya mekanisme yang menghasilkan open-ended evolution secara scalable dalam uji mereka).

**Engine (M0):**
- Rust, bit-packed `u64`, multithreaded (20 thread), integer/bit ops murni — **tanpa float di substrat** → determinisme bit-identical by construction.
- Snapshot biner berversi + manifest JSON (seed, rule-id, size, step, hash).
- Streaming snapshot (RAM constraint); ring buffer frame terbaru.
- Benchmark harness: cell-update/detik, dilaporkan apa adanya.

### Keluarga flow NCCA (amendemen M0, disetujui 2026-09-22)

**Konstruksi inti:** v′ᵢ = vᵢ − F(vᵢ₋₁, vᵢ, vᵢ₊₁) + F(vᵢ₋₂, vᵢ₋₁, vᵢ) — F = fungsi aliran edge (i→i+1), kapasitas 0 ≤ F ≤ min(pengirim, ruang-penerima). Konservasi **by construction** (telescoping): ruang pencarian M1 tertutup terhadap pelanggaran konservasi. Rule 184 = anggota k=1 (F = c AND NOT r) — kesinambungan LM0. Tabel F di-clip saat load → evaluasi = LUT murni; keluarga tertutup terhadap mutasi (penting untuk M1).

**Parameter M0:** k ∈ {1,2,4,8} (bit-packed u64), 1D ring, update sinkron, radius 1. **Ditunda terdokumentasi** (dibuka di M1 bila pencarian menuntut): 2D, update asinkron, radius > 1. `builtin:184` tetap lewat jalur bit-parallel k=1 yang ada.

**Multithread:** partisi statis per word, double buffer, nol sinkronisasi di hot loop (state lama read-only). Determinisme independen jumlah thread → **K1′**: run 1-thread ≡ 20-thread bit-identical.

**Snapshot v2:** header versi + field `k`; rule identity = file `rule.bin` + `rule_fnv` di manifest (target verifikasi eksak Newton, W2); window dengan byte budget (default 256 MiB), `window_states` aktual tercatat. Backward compat v1 (k=1) wajib.

**Protokol K2 (dibekukan):** jalur generik LUT, k=4, n=2²⁷, 100 langkah, median 5 run setelah 1 warmup, tabel F acak seeded, hardware+threads+hash dicetak. Target ≥10⁹ cell-update/detik. Dilaporkan apa adanya.

### M1 — Physics Design Search (amendemen, disetujui 2026-09-22)

**Definisi operasional (dibekukan SEBELUM pencarian):**
- **Partikel:** pada t, background b = nilai sel terbanyak (tie → nilai terkecil). Partikel = run kontigu sel ≠ b, lebar ≤ 8, terbungkus sel = b. Bertahan = interval overlap (geser ≤ max-flow per langkah) dengan massa setara di t+Δ; merge/pisasah = mati objek. Detektor = fungsi murni atas sekuens state, diverifikasi dengan sekuens sintetis.
- **Competitive exclusion:** fraksi sel yang 3-cell neighborhood-nya termasuk top-3 pola ≥ 0,8 bertahan ≥ 10⁴ langkah (10 titik observasi berurutan, probe-every 10³).
- **K3 = konjungsi:** partikel persisten DAN tanpa exclusion dalam horizon H = 10⁶. T_persist (satuan langkah fisika = observasi × probe-every; pelajaran dua bug satuan run 1-2): di tahap C (horizon) = 5×10⁴ langkah (5% H); di tahap A (probe 2×10⁴ langkah) = 5×10³ langkah (25% horizon probe). Jangan terapkan skala horizon ke probe — kriteria harus terdefinisi mungkin di skala pengukurannya. Kompressibilitas window dilaporkan sebagai pembeda noise vs struktur.

**Strategi:** tiga tahap — (A) 2×10⁴ tabel acak seeded k∈{2,4}, probe n=4096×2×10⁴; (B) mutasi re-clip hill-climbing (diberi label jujur) n=16384×10⁵; (C) juara → horizon H=10⁶, manifest lengkap. Seed hand-designed (sandpile, lapisan-184) dijalankan SELALU sebagai baseline kalibrasi. Hasil nihil = temuan negatif terdokumentasi + eskalasi sebelum klaim "sulit".

**Failure classes terdaftar:** FM-A detektor longgar (guard: persist+bergerak, baseline 184); FM-B keberagaman-noise (guard: konjungsi + kompresibilitas); FM-C exclusion pasca-horizon (guard: H dilaporkan, bukan klaim keabadian); FM-D nihil (guard: eskalasi seed terstruktur).

### M3-percepatan — Newton vs semesta tak dikenal (amendemen, disetujui 2026-09-22)

**Target:** juara M1 #1 & #2 (k=4, hukum hanya pegangan kita sebagai rule.bin). Mikro TIDAK via enumerasi (4.096 entri) melainkan **aljabar medan aliran**: dᵢ = vᵢ − newᵢ = fᵢ − fᵢ₋₁ → f terpulihkan via prefix-sum hingga satu konstanta, terkunci oleh edge aliran-nol (c=0 atau r=max → F=0 pasti). Entri tabel diisi dari tiap neighborhood teramati; konflik antar-pasangan = kegagalan keras.

**Kriteria biner M3-percepatan:** (3a) tabel pulihan ≡ GT eksak pada SEMUA entri ter-amati (tak-teramati dilaporkan jujur); (3b) gerbang reproduksi: tabel pulihan mereproduksi window held-out bit-identik; (3c) counterfactual law shift: pemulihan pada juara #2 menghasilkan tabel BERBEDA yang cocok GT-nya sendiri (pembinas hafalan). Makro dilaporkan terpisah: J(ρ) juara via --init-cap sweep (ρ dari sel uniform [0,m]), fit piecewise-linear MDL, held-out MAE < ε dari lantai derau; kegagalan fit = hasil ilmiah sah (semesta tak wajib berhukum makro sederhana).

**Failure classes:** FM-E konstanta tak terkunci (laporkan ambigu, jangan mengarang); FM-F coverage entri rendah (window transien, F1); FM-G J(ρ) tak mulus (makro negatif jujur, mikro tetap divalidasi).

### M4 — Loop tertutup + kurva growth-rate (amendemen, disetujui 2026-09-22)

**Kejujuran di muka:** K5 tidak menuntut kurva tumbuh tanpa batas; R1 tetap pertanyaan terbuka (§11). M4 menyalakan instrumen dan membaca apa adanya.

**Loop v1 (W3) — discover → intervene → verify:** iterasi i: Newton mengamati Fᵢ (medan aliran + J); mengidentifikasi entri IKAT (cap(e)>0, F[e]=cap(e), sering teramati — kemacetan eksak) dan entri LONGGAR aktif (F[e]<cap(e), teramati terbanyak). Intervensi terarah: +1 pada M=64 entri longgar tersibuk; kontrol: +1 pada 64 entri longgar acak (besaran sama, tanpa arah). Prediksi: J_max (cap tertinggi) naik lebih besar lewat intervensi terarah. **W3 biner: rerata ΔJ_max terarah > kontrol, konsisten K=4 iterasi.** Bukan klaim open-endedness — bukti loop: temuan → intervensi → konsekuensi terverifikasi.

**Growth meter (K5/W4):** model_bits(t) = k × entri teramati pada window sekitar t + bit makro; checkpoint t ∈ {10³, 10⁴, 10⁶}; tiga rezim: juara A, juara B (counterfactual M3), 184 (rezim runtuh). Kompresi window (zlib) per checkpoint dilaporkan (W4). Kurva dilaporkan apa adanya — saturasi = pembacaan sah instrumen.

**Failure classes:** FM-H intervensi tak menggeser J (audit definisi ikat; nihil = temuan); FM-I kenaikan model_bits artefact coverage (laporkan berdampingan dengan kurva coverage); FM-J kontrol kebetulan menggeser (K iterasi + uji arah).

## 6. Newton

**Tahap A — struktur dulu** (pelajaran Crutchfield: filter domain/partikel dibangun tangan sebelum persamaan gerak bisa diturunkan → kita otomatiskan tahap ini): deteksi partikel/domain/defect dari bitstream tanpa asumsi bentuk.

**Tahap B — dinamika** (teknik dari bukti head-to-head): hybrid tiga komponen —
1. **Parsimoni eksplisit** (MDL/posterior) untuk seleksi model — bukan akurasi saja.
2. **Proposal terpelajar** (neural-guided decomposition ala AI Feynman yang menaikkan 71%→100%) untuk pencarian.
3. **Verifier eksak** sebagai gerbang penerimaan — mencegah konfabulasi (pelajaran FunSearch).

**Larangan teknis:** GP/EA murni sebagai tulang punggung (kalah di semua head-to-head); sparse-library (SINDy) untuk hukum makro (hukum emergen kemungkinan tidak ada di pustaka manusia; library tumbuh faktorial terhadap dimensi); asumsi toleransi noise (semesta kita bebas noise — itu keunggulan, bukan alasan malas).

**Protokol verifikasi:** (a) akurasi pemulihan vs source code; (b) **counterfactual law shift** (pola NewtonBench: geser hukum mikro → semesta baru → hukum makro tersembunyi) sebagai tes ketahanan hafalan sekaligus verifikasi eksak.

**Anggaran realistis:** biaya pencarian eksponensial terhadap kompleksitas hukum dan kuadratik terhadap dimensi (Schmidt–Lipson: 30 jam untuk double pendulum). Desain harus mengasumsikan pencarian terbatas — bukan brute force.

## 7. Metrik & Teori

**Tiang 1 — definisi operasional (kontribusi kita):** semesta disebut open-ended bila **ukuran model terbaik Newton tumbuh persisten** — bit model per satuan waktu semesta. Mengadopsi + mengkuantifikasi Hughes et al. 2024 ("novel + learnable", observer-dependent). Ground truth membuatnya terverifikasi, bukan anekdotal.

**Tiang 2 — komparabilitas:** Bedau evolutionary activity (class 1/2/3), Adami physical complexity (bit mutual information genom–lingkungan), Adams unbounded evolution (non-repetisi vs waktu rekurensi Poincaré), complexity profile berbasis kompresi (zstd). Hasil wajib dilaporkan dalam bahasa ini.

**Tiang 3 — oracle (unik):** akurasi pemulihan vs source code; counterfactual shift; efek feedback (perubahan lintasan evolusi akibat temuan Newton).

## 8. Desain-sekitar Kegagalan

**Mode kegagalan universal: competitive exclusion.** Semua sistem spasial dalam scan berakhir dominasi satu/beberapa spesies (Lenia: goo/LEP; evoloop: regresi ukuran; Tierra: 8 kelas terkecil; Echo: bounded class 2).

Mitigasi ber-bukti (belum terbukti untuk horizon tak terbatas — jujur): mass conservation + energy constraints; aturan bergantung-state; lingkungan dinamis.

**Tiga asumsi terlarang** (dibantah/tidak didukung sumber primer):
1. Konstruktor universal ⇒ kompleksitas tumbuh (von Neumann 1966 belum pernah dipakai untuk evolusi Darwinian).
2. Konservasi/reversibilitas ⇒ open-endedness.
3. Keanekaragaman bentuk ⇒ evolvability (Lenia >400 spesies, tetap konvergen).

### LM0 — Loop Miniature (amendemen 2026-09-22)

**Prinsip: kopling sebelum katedral.** Objek novel proyek ini adalah loop (syarat (iv) kosong); data pertama dari kelas objek yang belum pernah dijalankan siapa pun lebih berharga daripada perf prematur. Risiko terbesar (R1, R3) dikeluarkan dari posisi paling akhir (M3/M4) ke posisi paling awal.

**Ruang lingkup:** semesta mainan — CA 1D ring N sel (default 4096), k=1, NCCA Rule 184 (traffic rule; konservasi partikel native; hukum makro emergen tanaman = fundamental diagram J(ρ)); Newton v0 (Python): pemulihan mikro ekshaustif atas 2^8 aturan + hukum makro piecewise-linear via MDL; oracle; meter T1. Determinisme K1, format snapshot/manifest, dan file seam memakai **format final dari hari satu**; kernel perf = mainan (K2 tetap milik M0); single-thread.

**LM-1 — eksperimen hukum tanaman (kriteria biner LM0):**
1. **Mikro:** rule table dipulihkan eksak dari window (kelas 1D radius-1, 256 kandidat).
2. **Makro:** J(ρ) dipulihkan dari sweep densitas — train pada subset ρ, prediksi held-out, MAE < 0.02 terhadap ground truth terukur dari run panjang (bukan rumus tekstbook). Bacaan penentu LM0 = makro (mikro sudah dibuktikan mungkin oleh AutomataGPT 82%; R3 hidup di makro).
3. **Meter T1** emit (waktu semesta, bit model terbaik) — angka pertama proyek.
4. **K1** berlaku dua arah: re-run bit-identical lintas proses DAN lintas implementasi (engine Rust ≡ CA referensi Python).

**Kelas kegagalan terdaftar di muka (pre-mortem):** F1 Newton tidak menemukan apa pun → ruang hipotesis terlalu kecil / fitur salah; F2 meter datar padahal hukum ada → meter rusak; F3 model sampai lolos → gerbang verifier dirapatkan. Ketiganya mungkin terjadi di skala mainan — itulah pointnya: gagal murah, beli informasi.
